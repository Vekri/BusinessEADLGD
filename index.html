Business EAD assessment

One facility in, an exposure at default out. Probability of default and loss given default then turn that exposure into an expected loss.

Business problem

A lender has to know, for every business facility, how much it will still be owed if the borrower defaults. On a revolving line the statement balance is only the amount drawn today. The borrower can still use part of the unused limit before default.

Exposure at Default (EAD) is that amount. For a business loan it is the outstanding principal, including the current balance, plus an estimate of how much of the unused limit will be drawn. That estimate is the credit conversion factor (CCF) times the undrawn limit.

The five facilities below are a teaching book. A live book would set the CCF from the institution’s own record of drawdown before default. A facility that is already fully drawn has an undrawn limit of zero, so its EAD is the current balance.

How this helps

One identity, every file

The same checks and the same formula run on each facility, so the exposures can be compared across the book.

A rupee amount

The result is the exposure at default, in rupees, together with the part that is still undrawn today.

The reason stays visible

Each stage is written down: the inputs, the checks, the undrawn limit, the expected draw, and the EAD.

Balance and draw stay apart

The amount already owed and the amount still expected to be drawn are shown separately, then added.

The calculation

EAD on this page is an identity. The undrawn limit is the loan limit minus the current balance. The expected draw is the CCF times that undrawn limit. EAD adds the expected draw to the current balance.

EAD = Current balance + CCF × Undrawn limit

L001 works out as ₹70,00,000 + 50% × ₹30,00,000 = ₹85,00,000.

Loan limit→ Current balance→ Undrawn limit→ CCF × undrawn→ EAD

The credit conversion factor

The share of the unused limit the bank expects the borrower to draw before default. 50% of ₹30,00,000 is ₹15,00,000.

The example book

Five facilities, each reduced with the same identity, so the rupee amounts can be read side by side.

What goes into the identity

Loan limit

The sanctioned amount. The borrower cannot draw more than this.

Current balance

The amount already drawn and still outstanding on the assessment date.

Undrawn limit

Loan limit minus current balance. This is the room left to draw.

CCF

The fraction of that room expected to be used before default. Enter it as a percent.

Expected loss

The same five loans can be read with the probability of default and the loss given default. PD is how likely default is. EAD is how much will be owed if it happens. LGD is the share of that amount the bank does not recover. Expected loss multiplies the three.

Expected loss = PD × EAD × LGD

L001 is 5% × ₹85L × 30% = ₹1.275L. That is ₹1,27,500. One lakh (1L) is ₹1,00,000. Select a row to load the loan, including its PD and LGD.

PD× EAD× LGD→ Expected loss

PD

The probability the borrower defaults. These rates are the teaching inputs for this book.

EAD

The exposure from the identity above. ₹85L is the ₹85,00,000 on L001.

LGD

The share of EAD lost if default occurs. Expected loss weights that share by the PD.

How a facility is read

  1. Limit and balance. The sanctioned limit and the amount already drawn.
  2. Undrawn limit. Limit minus balance. The figure on the file has to match.
  3. CCF. The share of the undrawn limit expected to be drawn before default.
  4. Expected draw. CCF times the undrawn limit.
  5. EAD. Current balance plus the expected draw.
  6. Expected loss. PD times that EAD times LGD.

What you will see

Enter a facility, or use High undrawn and Mostly drawn, then choose Run assessment. You can also select a row in either book. The review appears in this order:

  1. Facility received. The figures you entered, including PD and LGD.
  2. Data checks. Limit, balance, undrawn limit, CCF, PD, and LGD, each pass or fail.
  3. Undrawn limit. Loan limit minus current balance.
  4. Expected draw. The credit conversion factor times the undrawn limit.
  5. Exposure at default. Current balance plus the expected draw.
  6. Expected loss. PD times EAD times LGD.
  7. Assessment. One sentence with the loan, the EAD, and the expected loss.
